# STM32G431-BareMetal-Gimbal-Control
A bare-metal C firmware (CMSIS) and custom 75x75mm 4-layer PCB (Altium Designer) project for a 3-axis BLDC drone gimbal using STM32G431. Features a 100 Hz PID loop, Complementary Filter, and TIM1 SPWM motor driver, fully validated via MATLAB/Simulink dynamic simulations.
